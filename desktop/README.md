# 墨评 macOS 应用

从已准备好的干净源码运行 `python3 desktop/build_app.py --output /a/new/output/directory`，双击“墨评.app”打开独立系统 WebKit 窗口。依赖本机源码、`.venv` 与已安装的评分模型，不是可移机的完整发行包。

正式窗口使用既有安全启动器、8766端口及 `~/Library/Application Support/InkwiseK12/workspace`，保留原有作业、教师复核和成功报告。应用不会自动迁移数据库、重新评分或启用云端。缺少配置或模型时保留诊断与重试提示，不伪造分数。教师仍需使用原访问凭据登录，凭据只在页面内存中。

作业列表采用固定纸白与黛红侧栏，当前作业的原稿、报告复核、修订和记录仍按原流程操作。未保存内容的关闭确认保持有效，导出继续要求终稿就绪检查。关窗保留项目后台，避免中断已有任务；停止后台使用原启动器 `--stop`。

原生检查仅使用19014端口、独立练习目录和非持久 WebKit，不提交评分，也不读取正式作业。构建包不含凭据、数据库、原稿、报告或模型；采用本机临时签名，未作公证发行。
