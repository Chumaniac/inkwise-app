# 墨评 使用说明

## 主流程

新作业/上传原稿 → 确认文字 → 真实评分 → 教师逐项复核 → 导出绑定原文版本的报告

1. 先按模型配置说明准备本机服务。首次启动会建立私人练习工作区与访问文件；把 teacher-access.txt 中的凭据填入登录框，关闭时清除会话。
2. 选择练习量规，粘贴合成作文或上传获授权原稿。检查 OCR 不确定行，确认文字后再提交评分。模型错误会原样转成可处理失败，不补造分数。
3. 教师逐项核对引用依据、维度分数与评语，明确保存复核。导出报告时检查作业/文字/规则版本；旧成功报告继续保留。

## 操作原则

先用合成示例验证，再导入自己的获授权资料。必填项旁的提示说明预期格式；处理时等待明确的完成/失败状态，不连续重复提交。保存后先重新打开记录核对，再导出。空状态不会伪造历史数据；错误不自动转为成功结果。

## 目录与恢复

macOS：~/Library/Application Support/InkwiseK12/workspace；其他系统：~/.local/share/inkwise-k12/workspace。首次建立的 teacher-access.txt 是私人访问文件，不能上传或分享。

迁移电脑时先正常退出应用，确认没有在途任务，备份整个私人数据目录；安装同版程序后恢复到相同位置。不要只复制数据库主文件而漏掉 WAL、附件或规则。版本不兼容时先备份，再按显式升级检查处理，不删除数据库以“修好”程序。

## 移动端与键盘

网页提供窄屏布局与可滚动表格。桌面包运行在当前电脑，本机回环地址不能直接在另一部手机打开；这不是已部署的手机云服务。用 Tab 在控件间移动，焦点可见；降低动态效果的系统偏好会被保留。

## 能力条件

练习包内的13套量规为合成草案，不是学校批准标准。模型文件不随源码/桌面包再分发。可选向量检索、Kafka 长任务和学校实际评阅需要单独配置与验收；默认本地规则回退会要求教师复核。禁止把真实学生文本、图片、访问文件或原始服务响应提交到仓库。

## 关闭窗口与停止后台

关闭桌面窗口会保留已启动的评分/采集后台，避免中断在途任务。再次打开同一安装位置时，会验证原进程、脚本与端口归属后重新连接，不启动第二套服务。

需要完全停止或移动/更新程序时，先确认没有在途任务，再用安装包中启动器的 --stop。若程序位于 ~/Applications：

```sh
inkwise_runtime="$HOME/Applications/墨评.app/Contents/Resources/runtime"
"$inkwise_runtime/python/bin/python3" "$inkwise_runtime/app/scripts/start_local.py" --stop
```

归属不符时启动器会拒绝停止，不会结束未知服务。数据库、原稿、规则和报告均保留。
