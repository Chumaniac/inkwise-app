# 用户功能验收 · 0.5.1

## 2026-10-29 案例回流后续核对

已确认评分报告中的“案例候选状态”会区分尚未提交、待审核、已退回、已审核与已撤回。填写脱敏正文、说明和授权后提交，核对保存的候选编号；选择“打开候选审核”可定位当前记录。候选不在列表首屏时仍可打开，“查看全部候选”恢复分页目录。

退回意见保留在卡片中。作者明确选择“修改候选”，重新核对脱敏内容和使用授权后提交；另一名有权限的教研审核者再作决定。修改不会自动沿用授权勾选，也不会改写原成绩或自行入库。任务记录能读到提交、退回、修订和通过结果。

提交超时或结果未确认时先读取状态，原填写内容保留。刷新或翻页会先确认未保存修改；保存一张卡片不会替换另一张卡片的草稿。读取最多保留一个当前摘要和20条目录，直接详情只读取一份候选；读取及候选操作以30秒为等待上限，未知写入不自动重复。以上为隔离合成数据的软件核对，未作真实学校或模型效果验收。

2026-10-12，按本次要求从教师、教研审核者和管理员的使用流程验收。以下场景已在本机真实 Chrome 与隔离合成账号中通过。

|用户操作|验收结果|
|---|---|
|登录失败后重新登录；查看历史、搜索和翻页|可恢复，列表可继续访问|
|创建任务、填写练习、检查语言|任务与表单正常；新任务重新取得云端授权|
|上传多页、调整顺序、核对原文、替换失败页|识别、原稿查看及存档可用，成功页复用|
|原稿切页时编辑教师评语|未保存修改保留；导出前要求先保存|
|查看评分、解释报告、修改评语、确认并下载|五维报告和下载内容一致；教师确认后不能被取消|
|仅校对并确认建议|正常显示建议，不产生分数|
|提交脱敏案例、修改候选、查看与翻页|保存内容一致，不复制原始私密评语|
|教研退回 → 教师阅读原因 → 修改重提 → 独立审核通过|完整往返通过；退回原因已补充显示|
|管理员查看改进建议与不足原因|显示中文说明，证据不足时不会启用新规则|
|取消任务；处理失败后重试|状态明确，原文保留；未配置模型不会伪造评分|
|退出账号、手机使用、短暂请求失败|清空旧账号内容，无页面横向溢出，轮询可恢复|

新增等待说明用于长文或OCR处理，可返回历史查看；展示实际阶段，不承诺虚假的剩余秒数。历史15,000字符真实本机模型报告已复用验证五维展示、解释、教师确认及下载，没有重做推理；该内容是项目自己的合成长文。

复验入口为 `tests/browser_acceptance.cjs` 和 `tests/user_acceptance.cjs`。本机验收服务 `tests/serve_browser_fixture.py` 仅在显式合成模式下运行；后一场景还需显式启用既有报告复用。测试凭据仅属于一次性合成账号，不能用于正式系统。

这是使用流程验收。学校正式量规/评分一致性、复杂学生手写识别效果、真实云端服务及完整长文1.5秒目标不在本次通过声明内；此前公开样本和本机模型实测结论保持原样。没有部署服务器或更新在线演示。
