# 首稿与修订稿

打开教师已确认的评分报告，选择“修改对照”。可以新建修订稿，或打开已有记录继续处理。每篇最多保留 3 份修订稿，分别以首稿为起点。

修改正文后保存，再查看首稿与修订稿的文本差异。逐项记录原意见“已处理”或“仍需修改”，保存后明确确认本次修改记录。确认后的修订稿只读；“仍需修改”继续显示，不会被当作已经解决。

首稿、评分报告和教师结论继续使用原有已确认记录。修订稿固定首稿文字版本以及正文、报告、量规和教师结论的摘要；任何内容不一致都会阻止对照。原引用仍通过首稿的版本与图片摘要定位，不迁移到新稿。此流程不重新 OCR、评分、修改首稿成绩或授权教学案例回流。当前支持评分报告，独立校对报告保持原流程。

读取和写入都重新检查租户与班级范围；教师或管理员可以修改，教研身份只读。新建请求带幂等键；保存和确认采用修订稿自己的版本，冲突保留当前编辑。退出或切换作业会取消旧读取并释放当前稿件与差异，不把正文写入浏览器长期存储。

每稿沿用 15,000 字符上限。列表只读取最多 3 条摘要；差异计算最多比较 512 个句段，较大变化合并为片段显示。保存前检查本机存储余量，失败不替换旧记录。学校管理员的既有内容清除流程同时清除关联修订稿；导出文件与备份仍需按原清除流程单独处理。

## 本机升级

本次只新增 `writing_revisions` 表，不改变已有任务表字段。启动新版本前，用选定的私有配置运行 `inkwise --env-file /path/to/private/.env init-db`。先备份原数据库，在隔离副本上验证初始化与旧行摘要，再更新本机版本。配置文件不进入发布包。

已有修订记录时，不应让不认识该表的旧版本负责内容清除。当前源码的 `upgrade-check --target-data-feature baseline/v1` 会拒绝这种降级；旧启动器本身不认识新检查。旧安装仍保留，只使用独立旧数据副本核对。没有新修订数据时可验证旧版启动和恢复到新版。

工程验收使用合成原稿与既有成功报告，覆盖完整使用流程、重开、权限、旧版本冲突、容量、文本原样保存和内容清除。模型效果、学校实际使用和生产部署按各自证据记录。

## 确认修订后的独立复评（当前源码）

确认修改记录后，可单独勾选“提交本地模型复评”。服务固定首稿的量规、修订文字版本和内容摘要，原报告保留；每份修订只创建一个独立 Job，复用现有队列、租户容量、租约、调用回执、取消、失败恢复及教师审核。重复点击或换幂等键仍返回同一任务。文字没有改变时直接提示复用原评阅，不再入队。

复评默认本地路由，不继承云付费、云同意或试验参与。模型未配置、结果未知、超时或失败时沿用原有明确状态，不合成分数，也不自动重发未知调用。新任务的正文、量规和来源不能替换；来源改变时在每次调用前和报告保存前拦截。复评任务不能再派生复评树；原首稿最多3份修订、每份1个子任务。

“查看复评状态”只读当前关联证据，打开独立任务后使用原教师界面复核。对比区固定5个维度，分别标出首稿教师终评、修订模型初评或修订教师终评。教师确认前不显示分差；确认后仅显示两次保存结论的差值，并提示模型/流程版本缺失、不同或聚合条件改变。差值不直接证明教学效果或模型准确率。教研案例审核角色不具备课堂成绩确认权限。

新增接口：`POST/GET /api/v1/jobs/{jobId}/revisions/{revisionId}/reassessment`。提交要求当前修订版本、严格 `confirmed: true` 和 `Idempotency-Key`，以及同租户/班级的教师或管理员权限。只读复核沿用已有班级访问权限。正文、原报告与模型原始响应不进入新增审计事件。关联记录与任务在同一事务中入库，沿用租户串行容量门禁。

管理员清除首稿时，同时清除最多3个关联复评的正文、报告、评语、模型回执内容和修订稿，并撤销在途租约；晚到结果不能写回。已导出内容仍需原有外部存储清理。删除子任务内容不会删除首稿。

已有数据库须由运营人员备份后显式运行原 `inkwise init-db`，追加 `revision_assessments` 表及唯一约束/关联；API启动不自动初始化或迁移。本轮只在隔离合成数据库验证，未迁移用户或生产数据、替换安装版或调用真实模型。

独立借鉴 [Canvas Submissions](https://developerdocs.instructure.com/services/canvas/resources/submissions) 中作业尝试与当前审核状态的绑定，以及 [Moodle 作业提交](https://docs.moodle.org/en/Assignment_settings) 的修订、重新提交和教师评定分离。仅采用机制，未复制上游代码或引入其服务。


修订与复评工作区保留同一份编辑表单。切回报告、原稿或记录后再返回，不会重新装入草稿；选择另一份修订或作业仍会确认未保存修改。打开已确认修订稿会先读取已有复评状态，保留五维比较和教师确认区分。状态未读到时只允许刷新核对，不自动提交或重新评分。列表刷新与复评读取彼此独立；所有返回仍绑定当前作业、修订及版本。

## 从独立复评返回修改对照

独立复评任务的标题下可选择“返回首稿与修改对照”。页面读取服务保存的首稿、修订编号和版本，再核对这份修订关联的独立任务。失败或取消的复评也能返回查看原因；模型初评和教师终评继续按各自状态显示。返回过程只读取已有记录，不提交、重试或重新评分。

存在未保存修改时先确认是否离开。取消返回、来源无权读取、网络失败或作业读取超过30秒时，当前编辑仍保留；作业读取成功才切换视图。改选其他作业或退出会取消旧读取，迟到响应不会覆盖新选择。读取列表、图片或状态的失败各自提示，不把已成功打开的作业误报为未打开。被清除、关联不一致或版本不符的内容不显示为有效对照。

2026-10-29 使用既有合成报告副本，构造失败、取消、待审核和已审核状态，经本机API、数据库和Chrome验证返回、五维显示、拒绝读取与未保存保护；原记录保持，返回过程业务写入和模型/OCR调用均为0。浏览器拒绝读取使用模拟404，跨班级及来源字段不可伪造另由真实API测试覆盖。未验证真实学校数据、模型效果或生产部署。
